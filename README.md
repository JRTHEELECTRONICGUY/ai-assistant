# JR AI Assistant
This is a customizable AI assistant that integrates the JR the Electronic Guy agent with an ethics core to ensure actions are aligned with predefined guidelines.
- **ethics_core.py**: Handles ethical decision-making.
- **ai_agent.py**: Processes user inputs and provides responses.
- **decision_engine.py**: Integrates the agent and ethics core.
- **logger.py**: Tracks actions taken by the assistant.
- **file_manager.py**: Handles input and output data management.
- **main.py**: The entry point to run the assistant.

## Usage
1. Run `main.py` to start the assistant.
2. Interact with the assistant via the command line.
3. Type "exit" to quit the program.
